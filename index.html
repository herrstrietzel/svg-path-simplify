Path vs. Shape?

SVG shapes can often be more concise if they fall into the category of »primitives« – so all significant geometrical parameters are described by a discrete number of parameters. Elements of this class are <circle>, <ellipse>, <ellipse> and <line>. Besides, rimitives support relative percentages as units – handy for fluid layouts. The <polygon> and <polyline> don't fall into this category as the most significant attribute <points> (specifying the vertices) allows an arbitrary array of point. These poly elements can always be expressed more concisely with a <path> element as paths support advanced minifications such as relative commands and shorthands for horizontal or vertical segments.
